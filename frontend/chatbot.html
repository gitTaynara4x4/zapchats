    Ajuda rápida

    Qual automação eu uso?

    Explicação bem simples para escolher entre resposta pronta ou menu de departamentos.

    Resposta automática simples

    É uma mensagem pronta que o sistema manda sozinho.

    Oi 10:30
    Olá! Seja bem-vindo(a).
    Em breve vamos te atender. 10:30
    1O cliente manda mensagem
    2O sistema responde sozinho
    3Pronto. A mensagem foi enviada.
    Use quando: você só quer mandar uma resposta pronta, sem escolher departamento.

    Menu para o cliente escolher departamento

    O cliente escolhe o departamento e vai para o lugar certo.

    Olá! Escolha uma opção:
    1 - Financeiro
    2 - Suporte
    3 - Comercial 10:30
    2 10:31
    Cliente enviado para: Suporte
    1O cliente recebe as opções
    2Ele escolhe um número
    3O sistema manda para o departamento certo
    Use quando: você tem departamentos como Vendas, Suporte ou Financeiro.

    Vai repetir toda hora?

    Não. O sistema foi feito para não incomodar o cliente.

    Resposta automática simples Manda uma vez quando o cliente chama. Se ele mandar mais mensagens em seguida, não fica repetindo. Padrão atual: espera 60 minutos sem conversa para poder aparecer de novo.
    Menu para escolher departamento Depois que o cliente escolhe Vendas, Suporte ou Financeiro, ele não precisa escolher de novo a cada mensagem. Padrão atual: o menu só volta depois de 6 horas ou quando o atendimento é encerrado.

    Qual eu escolho?

    Escolha só um modo principal. Os dois não ficam ligados ao mesmo tempo.

    Quero só responder “Oi, já vamos atender”. Use Resposta automática simples.
    Quero separar por Vendas, Suporte ou Financeiro. Use Menu para escolher departamento.
    Bem simples: “departamento” é o lugar interno que vai receber o atendimento. Exemplo: Vendas, Suporte ou Financeiro.
