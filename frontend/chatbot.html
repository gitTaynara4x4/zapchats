    Seleção de instância

    No topo da tela você escolhe qual WhatsApp quer configurar. Tudo que for salvo vale somente para a instância selecionada.

    Regra importante

    Você pode usar ou a resposta automática simples, ou o menu de filas. Os dois não ficam ativos juntos na mesma instância.

    Qual modo devo usar?

    Use “Resposta automática simples” se:

    1
    Você quer só cumprimentar o cliente automaticamente.
    2
    Você quer mandar mensagem fora do horário.
    3
    Você não precisa que o cliente escolha uma fila.

    Use “Menu para o cliente escolher a fila” se:

    1
    Você quer separar o atendimento por filas.
    2
    Você quer que o cliente escolha uma opção, como Comercial ou Financeiro.
    3
    Você quer que a conversa entre aguardando na fila escolhida pelo cliente.

    Menu para o cliente escolher a fila

    Esse modo é para quando o cliente precisa escolher uma fila, como Comercial, Financeiro, Suporte ou Cobrança. A fila não fica fixa no cliente. Ela só é aplicada no atendimento depois da escolha.

    1
    Ative o modo de escolha de fila.
    2
    Marque quais filas quer mostrar no menu.
    3
    Escreva a mensagem inicial que o cliente vai receber.
    4
    O cliente responde com o número da opção ou com o nome da fila.

    Exemplo real

    Cliente manda:
"Oi"

Cliente recebe:
"1 - Comercial
2 - Financeiro
3 - Suporte"

Cliente responde:
"2"

Cliente recebe:
"Perfeito! Vou te encaminhar para Financeiro."
    Dica importante: se você quer só cumprimentar o cliente automaticamente, use Resposta automática simples. Se você quer que ele escolha para onde quer ir, use Menu para o cliente escolher a fila.
